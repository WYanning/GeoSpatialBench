# L1 正式题型（28 类）

本模板继承 v3.9 跨城市共同关系：拓扑 9 类、方向 5 类、度量 8 类、顺序与复合 6 类。表中的问法是语义摘要；实际英文 prompt 由生成器统一产生。

## 拓扑关系 T（9）

| ID | 关系 | 正式设计要点 |
|---|---|---|
| T01 | equals | 点、线、面均覆盖；允许坐标顺序不同但拓扑相等 |
| T02 | disjoint | 优先近边界点—面、洞内点—面、近间隙线—面，点—点仅作控制题 |
| T03 | intersects | 独立标准谓词 yes/no；可与 equals/touches/crosses/overlaps 等同时为真 |
| T04 | touches | 按 GIS 标准谓词，不限于面—面；覆盖合理的点—线、线—线、线—面、面—面 |
| T05 | crosses | 以线—线、线—面为主要合法签名，不把面—面误作 crosses |
| T06 | contains / within | 主问题要求最具体方向关系；覆盖点、线、面作为被包含对象 |
| T08 | overlaps | 同维对象部分重叠，双方都不完全包含对方 |
| T09 | covers | 允许 B 落在 A 边界；与 contains 的内部约束区分 |
| T11 | strict contains | 项目继承定义：`contains(A,B) and not equals(A,B)`，不是库函数 `contains_properly` 的别名 |

拓扑主问题使用最具体标签优先级：`equals > contains > within > covers > overlaps > crosses > touches > intersects > disjoint`。T03 仍单独测试一般 `intersects` 谓词。

## 方向关系 D（5）

| ID | 关系 | 正式设计要点 |
|---|---|---|
| D01 | 四方向 | 只使用 N/E/S/W；每类方向题采用 PP=9、PA=4、AP=4、AA=8，非点对象使用质心 |
| D02 | 八方向 | N/NE/E/SE/S/SW/W/NW；与 D01 使用相同几何配额和质心规则 |
| D04 | 方位角 | 从北顺时针，允许圆周误差 ±1°；与 D01 使用相同几何配额和质心规则 |
| D05 | 观察者相对方向 | 观察位置固定为道路首个存储坐标，朝向末坐标 |
| D06 | 对象朝向 | 依据对象的存储坐标方向进行轴向分类 |

## 度量关系 M（8）

| ID | 关系 | 正式设计要点 |
|---|---|---|
| M01 | 欧氏距离 | 最小几何距离；PP=5，PL/PA/LL/LA/AA 各4题 |
| M02 | 边界距离 | 仅面—面，计算两区域边界之间的最短距离 |
| M04 | 曼哈顿距离 | 基于坐标差的 L1 距离 |
| M08 | Hausdorff 距离 | 对称离散 Hausdorff，Shapely `densify=0.25`，单位米 |
| M12 | 周长 | 总边界长度，包括外环和所有内孔环 |
| M14 | 给定距离内 | 用闭 buffer 判定；PP=5，PL/PA/LL/LA/AA 各4题 |
| M15 | 最近邻 | 仅在明确给出的四个候选中选择最近对象 |
| M18 | 密度 | 只计算明确提供的 P01–P10，边界点计入；除以区域 km²，保留三位小数 |

## 顺序与复合关系 O（6）

| ID | 关系 | 正式设计要点 |
|---|---|---|
| O01 | 线性顺序 | 以路线坐标存储方向为路线方向，对三个位置排序 |
| O02 | along-line before/after | 只考成对 before/after |
| O03 | 同侧/异侧 | 参考对象只用直线或明确局部切线；正式模板用直线 |
| O04 | 三点 between | 普通三点严格共线 between；模板探针在显示坐标上也精确成立 |
| O06 | 道路竖向顺序 | 在二维相交处比较道路 `layer`，允许 `same_layer` |
| O08 | 网络可达性 | 只把共享端点作为节点；内部几何相交不会自动连通，多步路径为 2–6 条边 |

## 暂缓、不生成的 4 类

`D03` 十六方向、`D07` 投影方向、`O07` 包含传递、`O09` 空间关系编辑/修改。它们仍保留在 deferred registry 中，不能被同事自行恢复到正式 L1。
